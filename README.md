✨ Overview

TOV Fashion is a complete ecommerce web application featuring product browsing, user authentication, shopping cart, admin dashboard, image uploads, secure REST APIs, and smooth deployment on AWS.

Designed with a focus on performance, security, and clean UI/UX.

🎨 Features
🌟 User Features

👗 Browse fashion products

🔍 Product details page

🛒 Add to cart / remove from cart

🚀 Fast checkout flow

🔐 Login & register

👤 User profile

🖼️ Image previews

🛠️ Admin Features

🔑 Admin authentication

➕ Add new products

✏️ Edit / delete products

📦 Manage orders

👥 Manage users

📊 Dashboard analytics

⚙️ Backend Features

🚀 Node.js + Express server

🔑 Session authentication

🗄️ MongoDB + Mongoose

🛡️ Protected routes

📁 Cloud image upload

📝 Structured API responses

💻 Frontend Features

⚡ React + Vite

🎛️ Context / Redux

🎨 Clean responsive UI

🔄 Axios API integration

📱 Mobile-friendly

🧩 Tech Stack
Layer	Technology
Frontend	React, Vite, TailwindCSS
Backend	Node.js, Express.js
Database	MongoDB Atlas
Authentication	Session
Deployment	AWS EC2, PM2, NGINX
